SSH / Dropbear / OpenSSH CVE-2023-48795 UNKNOWN* Brief description: Integer overflow in Diffie-Hellman key handling in Dropbear SSH (affects versions ≤ 2022.83) that may lead to remote code execution or denial-of-service in specific transport/extension negotiation scenarios.
Remediation: Apply vendor/maintainer patches or upgrade Dropbear/OpenSSH as recommended by vendor. If vendor patch not available, mitigate by restricting SSH exposure and enforcing strict algorithm/host-key policies. 		SSH access restricted to administrator networks; exposure reduced but not eliminated. Further reduction requires vendor patch and verifying device firmware contains the fix.
OpenSSL — X9.42 DH handling CVE-2023-5678 LOW (DoS) Brief description: Excessively long or specially crafted X9.42 DH parameters or checks can cause OpenSSL routines to be extremely slow or hang, enabling resource exhaustion (Denial-of-Service) when processing untrusted DH parameters.
Remediation: Apply OpenSSL security updates; ensure applications do not accept DH parameters from untrusted sources without validation; impose limits on parameter sizes/complexity. 		No immediate risk to user data if DH parameters are not accepted from untrusted sources. If service parses external DH parameters, consider sandboxing parse/validation or rejecting untrusted input.
OpenSSL — PKCS#12 parsing CVE-2024-0727 LOW (DoS) Brief description: Malformed PKCS#12 files may be parsed incorrectly by OpenSSL, leading to crashes (NULL dereference / DoS) when an application loads such files.
Remediation: Apply OpenSSL patches; do not parse PKCS#12 files from untrusted sources in privileged context; validate file format prior to parsing and sandbox any parsing operations. 		Low residual risk if PKCS#12 usage is limited to trusted administrative workflows. If file uploads are supported, isolate parsing and add input checks.
